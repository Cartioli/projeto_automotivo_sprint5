# Dashboard de Análise de Anúncios de Veículos

## Descrição do Projeto
Projeto desenvolvido em Python com Streamlit e Plotly Express para realizar a análise de dados sobre anúncios de vendas de carros nos EUA.

## Funcionalidades
- **Histograma Interativo:** Visualização da distribuição da quilometragem (odômetro) dos veículos.
- **Gráfico de Dispersão:** Análise da relação entre preço e quilometragem, categorizada pela condição do veículo.

## Tecnologias Utilizadas
- Python 3.9
- Pandas
- Streamlit
- Plotly Express
